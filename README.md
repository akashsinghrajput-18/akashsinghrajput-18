### 📚 3. Bookstore Analytics — SQL / MySQL

> End-to-end SQL analytics project simulating a real retail bookstore — from schema design to actionable business insights.

**📁 Project Structure:**
```
bookstore-analytics/
├── 01_schema.sql           # Tables & relationships
├── 02_data.sql             # Sample data
├── 03_sales_analysis.sql   # Revenue & bestsellers
├── 04_customer_analysis.sql # RFM & churn
├── 05_marketing_analysis.sql # Marketing ROI
├── 06_inventory_analysis.sql # Low stock alerts
└── 07_books_together.sql   # Market basket analysis
```

**🔍 Key Analyses:**
- 📈 Best-selling books by revenue
- 🔁 Repeat customer detection via order frequency
- 🧮 RFM Analysis (Recency · Frequency · Monetary)
- 📉 Churn detection using last purchase date
- 💸 Marketing ROI: Revenue vs. Acquisition Cost
- 📦 Low-stock inventory alerts
- 🛒 Market basket (books frequently bought together)
- 📅 Monthly revenue trend tracking

**🛠️ Tools:** `MySQL` `SQL` `MySQL Workbench`
